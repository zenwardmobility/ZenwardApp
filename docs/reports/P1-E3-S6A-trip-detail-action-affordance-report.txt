4. DEAD-CONTROL AUDIT
--------------------------------------------------------------------
A "dead control" is defined here as any element that (a) LOOKS enabled
(full-opacity, normal cursor, no honest disabled affordance) but (b)
performs no real, backend-verified action when activated.

Checked every clickable element on the page (`<button>` and `<a>`
elements) against this definition, by code inspection and live DOM
query:

  Edit Trip        -> genuinely disabled (opacity-50, cursor-not-allowed,
                       native `disabled`, no onClick). NOT a dead
                       control — it is an honestly-inert one.
  Report Issue     -> same treatment. NOT a dead control.
  Cancel Trip      -> enabled, real RPC. Not dead.
  Record No-Show   -> enabled (when shown), real RPC. Not dead.
  Contact Driver   -> enabled (when shown), real `tel:` href. Not dead.
  Manage Assignment/Assign Driver -> enabled, real route. Not dead.
  Add Note         -> enabled, real RLS insert. Not dead.
  Dialog "Cancel"/"Keep Trip"/close (X) buttons -> real `onClose`
                       state handlers, close the real open dialog.
                       Not dead.
  Breadcrumb "Trips" link, "Back to Trips" (unavailable state) ->
                       real `<Link href="/operations/trips">`. Not
                       dead.

No visibly-enabled control was found anywhere on Trip Detail that
performs no real action.

ENABLED DEAD CONTROLS FOUND: NONE.
