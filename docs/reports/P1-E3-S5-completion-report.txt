7. ACTIVE ASSIGNMENT QUERY / DERIVATION
--------------------------------------------------------------------
For every Trip, the embedded `trip_assignments` array is searched for
the row where `ended_at IS NULL` — never assumed to be the first/only
row. This is the sole source of "current driver" (work item §9/§18) —
never derived from any Trip column (none exists) and never from auth
identity (work item §18: "Driver ≠ AuthUser"). A Trip with no such row
is unassigned by construction — `unassignedTrips` filters on
`driverId === null`, never a separate persisted status (work item
§17).
