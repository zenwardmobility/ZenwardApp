3. IMPLEMENTATION
--------------------------------------------------------------------
`src/components/operations/OperationsSidebar.tsx`:
  - Added `import Image from "next/image";`.
  - Replaced both plain-text spans with a single `next/image`
    element:

      <Image
        src="/images/zenward-mobility-logo.png"
        alt="Zenward Mobility"
        width={217}
        height={72}
        priority
        className="h-auto w-9 lg:w-28"
      />

  - One element, not two hidden/shown variants — the existing
    "Zenward"/"Z" pair was two separate spans toggled with
    `hidden`/`lg:hidden`; the logo instead uses a single `<Image>`
    whose Tailwind width classes change per breakpoint
    (`w-9` = 36px in the `md` icon-only rail, `lg:w-28` = 112px at
    `lg`+), with `h-auto` preserving the asset's natural aspect
    ratio at both sizes. `width`/`height` props (217x72, matching the
    intrinsic 3.0:1 ratio) are required by `next/image` and are not
    the final rendered size — the `className` governs that.
  - No compact-only mark was fabricated for the `md` icon rail
    (768–1023px): work item §4 explicitly forbids inventing a
    separate unapproved logo for that state, and no second approved
    asset exists. The identical artwork is simply rendered smaller
    there (36px wide, ~12px tall) — the whole wordmark, never
    cropped, never distorted, never recolored.
  - The rail's own width (`md:w-16 lg:w-64`) and header height
    (`h-16`) were NOT changed — only the brand mark inside the
    existing header block.
  - `typography`/`cn` imports remain in use elsewhere in the file
    (nav item labels, location text, dispatcher name/role) —
    confirmed via grep before removing nothing else.
