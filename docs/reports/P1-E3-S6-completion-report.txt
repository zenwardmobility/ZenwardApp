5. SERVER DATA ARCHITECTURE
--------------------------------------------------------------------
`src/lib/operations/trip-detail.ts` — `getTripDetail()`, a focused
single-Trip lookup (work item §11): organization-scoped, explicit
columns, no service role, no broad SECURITY DEFINER read RPC (existing

via `Promise.all`.

assistance_notes, cancelled_at, cancellation_reason, no_show_at,
completed_at, created_at, updated_at` plus the embedded relationships
below. The route parameter is validated against a UUID regex BEFORE any
query runs (work item §8) — a malformed value never reaches Postgres.
